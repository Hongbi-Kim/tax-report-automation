# 08. 과제 안내 반영 (2026-11-21)

> 출처: 과제 안내 페이지 `…/chat/guide/` (표지 + 섹션 01~10을 읽음. 11번째 쪽은 페이지에 내용이 없어 확인하지 못함)

## 1. 안내에서 확인한 기준

| 구분 | 내용 | 지금 프로그램과의 관계 |
|---|---|---|
| 입력 | 같은 회사의 전기·당기 세무조정계산서 PDF 2개 | 맞음 |
| 처리 | 회사·연도 확인 → 값 추출 → 비교 | 맞음 (사업자번호·연속 연도 확인) |
| 출력 | **법인세 분석 보고서 + 조정료청구서** (고객에게 보낼 수 있는 형태) | 조정료청구서는 2026-11-21에 범위에서 뺐음 → **다시 범위 안으로** |
| 이번 과제 기준 | 보고서 숫자마다 어느 PDF·서식·페이지에서 왔는지 확인 가능 | 맞음 (표마다 근거 열, 부록 근거 대장 212건) |
| 보고서 6개 항목 | ① 주요 지표 비교(매출액·영업이익·당기순이익·부채비율 전기/당기/증감) ② 그래프(주요 손익·판관비 구성·재무상태) ③ 요약 코멘트 ④ 요약 손익 비교(금액·비율) ⑤ 판관비 주요 항목(전기·당기·증감·매출 대비 비중) ⑥ 세무조정·재무제표 특이사항 | **①②④⑤ 빠져 있음** (A-007 가정으로 제외했음) |
| 차수 | 4개 차수. 차수마다 새 자료를 받고 앞 프로그램을 계속 고침. 회사만 바꿔 반복 가능해야 함 | 회사·연도 하드코딩 없음. 서식 좌표는 국세청 서식 기준이라 다른 회사에도 그대로 쓸 수 있을 것으로 봄 (2차 자료로 검증 필요) |
| 담당자 | 자료는 **요청해야** 줌(무엇이·왜 필요한지 밝히면 파일을 채팅으로 보냄). 정해지지 않은 내용은 “확인해보고 말씀드릴게요”. 질문은 미리 모아 한 번에 | 지금까지 파일 요청은 하지 않았음 |
| 제출 | 최종 분석 보고서 **PDF 1개**, 자동 채점 | |
| 채점 | 회사 이름·사업연도·항목 이름이 보여야 함, **표 열 제목에 연도**, 억원·백만원 쓰면 **단위 표시** | 열 제목 “2025 사업연도” 형식 — 맞음 |
| 채점 | **«확인 필요»로 남긴 값은 정답으로 인정되지 않음** → 값을 확정할 자료를 받아 다시 실행 | «확인 필요» 값이 남아 있음(§3) |
| 채점 | 필수 항목을 모두 맞히고, 정해진 개수 이상 맞혀야 통과 | 필수 항목 목록은 공개되지 않음 → ①~⑥을 모두 넣는 것이 안전 |
| 채점 제외 | 코드, 조정료청구서, Excel, 검토 화면, 질문·답변 기록 | 청구서는 만들되 채점 대상은 아님 |

## 2. 바꿔야 할 것

### 2.1 보고서에 요구사항 ①②④⑤를 넣는다 (가정 A-007 폐기 제안)
- Q-011에 대한 담당자 답은 «답변 없음»(“아직 정해진 게 없어요”)이다. 하지만 과제 안내는 이 6개 항목을 보고서 구성으로 명시하고, 채점은 필수 항목을 맞혀야 통과한다.
- 빼면 채점에서 빠질 위험이 있고, 넣어도 Q-001 목차와 충돌하지 않게 할 수 있다. 그래서 **Q-001 목차(I~VIII)는 그대로 두고 기존 장 안에 넣는 방안**을 제안한다.

| 항목 | 넣을 위치(제안) | 단위 |
|---|---|---|
| ① 주요 지표 비교 | II장 앞 “(0) 주요 지표 비교” 또는 VII장 맨 앞 | 억원 (단위 표시) + 원 병기 |
| ② 그래프 3종 | VII장 요약 코멘트 앞 | |
| ④ 요약 손익 비교 | II장 (3) | 원, % |
| ⑤ 판관비 주요 항목 | II장 (4) | 원, 매출 대비 % |

- 숫자는 계속 표준재무제표 기준(Q-012)이고, 근거 열을 붙인다.

### 2.2 조정료청구서를 다시 만든다
- 사용자 지시(2026-11-21): 최종 프로그램 출력에 조정료청구서가 포함된다. 채점 대상은 아니다.
- 보수표가 없으므로 담당자에게 **파일을 요청**해야 한다(Q-002 다시 진행).

### 2.3 «확인 필요»를 줄이기 위해 자료를 요청한다
안내 원칙 “요청해야 받음”에 따라, 지금 «확인 필요»로 남은 값마다 필요한 자료를 정리한다.

| «확인 필요» 값 | 해결 방법 |
|---|---|
| 법인구분·법인종류·중소기업 여부 (I장) | 1) 신고서의 체크 표시를 이미지로 판독하는 기능 추가(기술적 해결), 2) 안 되면 담당자에게 확인 |
| 2024 법인지방소득세 (III장) | 2024 법인지방소득세 신고서 **파일 요청** |
| 2024 소득금액조정·공제감면 (V·VI장) | 2024 소득금액조정합계표·공제감면세액합계표 **파일 요청**, 서식이 원래 없다면 그 사실 확인 |
| 이월결손금 129,800원 차이 (IV장) | 담당자 확인 대기(Q-003). 차이 원인을 보여 주는 자료(예: 2024 결손금 관련 명세)를 요청 |
| 선납세금 vs 기납부세액 (III장, R15) | 선납세금 내역(중간예납·원천징수 납부서 등) 요청 |

## 3. 다음 질문 묶음 (담당자에게 한 번에 보낼 안)

안내 원칙: “어느 부분인지 · 무엇을 묻는지 · 왜 필요한지”를 밝히고, 미리 모아 한 번에 묻는다. 기술 용어 대신 업무 용어로 쓴다.

1. **[조정료청구서] 보수표 파일 요청** — 기본보수(매출액과 자산의 1/2 중 큰 금액 기준) 구간표, 공제·감면액 가산 비율, 부가세 포함 여부, 기존 청구서 양식을 보내 주실 수 있을까요? 보수표가 없으면 청구서 금액을 계산할 수 없습니다.
2. **[법인세 신고상황] 2024 법인지방소득세 신고서 요청** — 2024 세무조정계산서에는 법인지방소득세 신고서가 없어 2024년 지방소득세를 비워 두었습니다. 신고서를 보내 주시면 확정해서 넣겠습니다.
3. **[소득금액조정·공제감면] 2024 서식 요청** — 2024년 소득금액조정합계표와 공제감면세액합계표가 있으면 보내 주세요. 원래 작성하지 않은 서식이라면 그렇게 알려 주시면 “해당 없음”으로 적겠습니다.
4. **[이월결손금] 차이 자료 요청** — 2024 결손금 15,510,353원과 이월결손금 15,640,153원의 차이(129,800원)를 설명할 자료가 있으면 보내 주세요.
5. **[법인세 신고상황] 선납세금 내역 요청** — 2025 결산 자료에 선납세금 4,341,000원이 있는데 세액조정계산서 기납부세액 칸은 비어 있습니다. 납부 내역을 확인할 수 있는 자료를 보내 주실 수 있을까요?
6. **[기본정보] 법인구분·중소기업 여부 확인** — (체크 표시 판독 기능이 실패하는 경우에만) 신고서상 법인 종류와 중소기업 여부를 알려 주세요.
