## 2. 표기 규칙 (채점·검토용)

- **모든 표의 연도 열은 전기 → 당기 순서**, 열 제목에 연도와 단위를 적는다(예: `2023 사업연도 (원)`).
- 억원으로 줄일 때는 단위를 표시한다(`(억원)`).
- 섹션·항목 이름은 채점 항목 이름과 같게 쓴다: 손익계산서·재무상태표·분석 지표·판관비 주요 항목, 급여 총액.
- 항목 이름 뒤에 숫자(코드)를 붙이지 않는다. 계정 코드는 금액 뒤 별도 열.
- 숫자는 PDF 텍스트로 추출되어야 한다(`font-variant-numeric: tabular-nums` 사용 금지 — 4차에서 확인).
- 값 표시: 「–」 서식 칸 공란 · «확인 필요» 확정 불가 · ※ 자료 간 차이(원문 값 그대로) · A 가정 적용 · W 표준서식과 결산서 차이.

## 3. 주요 계산식

| 항목 | 식 |
|---|---|
| 억원 | 원 ÷ 100,000,000, 소수 둘째 자리 반올림 |
| 부채비율 | 부채총계 ÷ 자본총계 × 100 (자본총계 ≤ 0 이면 ‘자본잠식’) |
| 증감률 | (당기 − 전기) ÷ \|전기\| × 100, 부호 바뀌면 흑자전환·적자전환 |
| 판관비 기타 | 판매비와관리비 합계(코드67) − 상위 5개 계정 |
| 매출 대비 비중 | 항목 ÷ 표준 매출액 × 100 |
| 소득률·실효세율 | 각사업연도소득 ÷ 수입금액, 총부담세액 ÷ 과세표준(또는 소득), 기준금액 ≤ 0 이면 ‘해당 없음’ |
| 자본잠식률 | (자본금 − 자본총계) ÷ 자본금 × 100 |
| 가지급금 매출 대비 | 인정이자조정명세서(을) 잔액 ÷ 표준 매출액 × 100 |

## 4. 특이사항(Ⅷ) 판단 기준

- **매출처**: 외상매출금명세서의 기말 잔액 거래처 수·최대 거래처 비중을 같은 기준끼리만 비교(증감 열이 없는 명세서는 비교 불가 표시). 명세서에 가림이 있으면 거래처 수·비중 보류.
- **가수금**: 가수금명세서 거래처코드별 내역 + 표준 코드236/292, 없으면 같은 금액의 부채 계정을 ‘금액 일치 계정’으로 표시. ‘대표이사 가수금’ 같은 표현은 명세서 거래처명에 있을 때만.
- **가지급금**: 인정이자조정명세서(을)의 특수관계인별 기말 잔액 기준, 대여금 명세서와 대사, 표준 계정은 금액 일치로만 표시.
- **판관비 계정 변동**: 전기에만 금액이 있는 계정(소멸), 당기에만 있는 계정(신규).
- **자본잠식**: 자본총계 < 자본금이면 잠식률 표시, 해소 필요액은 기준 미정이라 «확인 필요»(Q-005).
