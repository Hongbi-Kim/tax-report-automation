# 03. 추출·검증 로직 (최종)

## 1. 서식 식별 (`pdfsrc.py`)

- 각 쪽 앞 7줄을 공백 없이 이어 붙여 **서식 제목 규칙**과 비교(우선순위 순). 제목이 여러 줄로 나뉜 포맷은 정규식 규칙(`법인세과세표준및.{0,60}세액조정계산서`).
- 제목이 없는 쪽은 ‘N쪽 중 제k쪽’ 표기나 직전 서식(공제감면·검토표·시산표·명세서)을 이어받는다.
- 결산부속명세서: 결산서 뒤 또는 이익잉여금처분계산서·전산조직운용명세서 뒤의 ‘○○명세서’ 한 줄 제목 쪽. 감가상각비 명세서·고정자산 관리대장은 별도 서식으로 제외.
- 「실습용: 회색 처리 금액은 확인 필요」 안내가 있는 쪽의 **채움색 (0.85~0.95) 회색 곡선 도형**을 가림 칸으로 기록(표 머리글 배경 사각형과 구분).

## 2. 칸 읽기 (`extract.cell`)

| PDF에 보이는 것 | 결과 |
|---|---|
| 숫자(쉼표 또는 `:` 구분) | 확정 |
| 숫자 대신 글자(예: 「확인중」) | «확인 필요», 플래그 `글자표기` |
| 회색 가림 도형과 겹침 | «확인 필요», 플래그 `가림` (0으로 보지 않음) |
| 아무것도 없음 | 공란(확정) — 계산에서는 0, 표시는 「–」 |
| 합계 칸이 빈칸인데 하위 항목이 가림·글자 | «확인 필요», 플래그 `합계빈칸` |

## 3. 서식별 읽기 규칙과 포맷 차이 대응

| 서식 | 규칙 | 포맷별로 추가된 처리 |
|---|---|---|
| 신고서 | 항목 번호(①~⑪)+항목명 정규식(글자 사이 공백 허용), 금액 줄은 항목명 뒤 첫 열 | `(33)` 같은 줄번호 제거, 회사명 `(10기)`·`(최종)` 제거, 표지 기수 `第2期`/`제10기` |
| 체크 표시 | ⑬법인구분·⑮종류별구분의 **동그라미 도형 안 글자** 판독 → 내국/외국, 코드(30=중소기업·기타법인) | 판독 실패 시 «확인 필요» |
| 세액조정계산서 | 「01」(결산서상당기순손익)·「29」(감면분추가납부세액)를 기준 좌표로 코드 열 결정 | 괄호에 붙은 코드 `)16`(3차), 한 글자씩 나뉜 코드 `2` `3`(4차) |
| 표준재무상태표·손익계산서 | 「코드」 머리글 x좌표로 코드 열·좌우 단 경계 | `:` 자리표시 없는 포맷, 금액+글자 붙은 토큰 분리, 두 줄 항목명 이어붙이기 |
| 결산서 재무상태표·손익계산서 | 대조용. 「(당)기」「(전)기」가 함께 있는 머리글 줄로 열 경계 | 없는 포맷(3·4차)은 대조 보류 |
| 자본금과적립금(갑) 결손금 | 사업연도 행, 열은 머리글 위치(⑥사업연도 기준 이동량 보정) | 날짜 `2014.12.31`, 여러 발생연도 행 |
| 소득금액조정합계표 | 「④과목」 위치로 좌(익금산입)·우(손금산입) | 위·아래 줄로 나뉜 과목명 |
| 공제감면세액합계표(갑) | **열 머리글(③대상세액 ④감면세액 ⑤전기이월액 ⑥당기발생액 ⑦공제세액)로 숫자의 의미 결정**. 적용액 = ④ 또는 ⑦ | 합계표가 없으면 같은 의미의 세액조정계산서 코드17+19로 적용액 확인 |
| 인정이자조정명세서(을) | 직책·성명, 적수 계산표 ‘계’ 줄의 기말 잔액 | 가지급금 대조 근거(3차) |
| 결산부속명세서 | 명세서 제목 단위 분리, 머리글(기초액·당기증가·당기감소·금액) 위치로 열 매핑 | `코드 상대거래처 적요 금액` 형식, 3~5자리 거래처코드 |

| ID | 내용 | 불일치 처리 |
|---|---|---|

| R02 | 세액조정계산서 01 = 표준 당기순손익 | 차이 |
| R03 | 01 + 02 − 03 = 04 | 차이 |
| R04 | 자산총계 = 부채총계 + 자본총계 | 차이 / 입력 미확정 시 보류 |
| R06 | 전기 표준재무제표 = 당기 PDF 결산서 전기열 | 서식 간 차이 |
| R07 | 전기 결손(과세표준) = 결손금 발생액·당기 이월결손금 공제액 | 충돌 — 숫자 보정 없이 차이 표시(Q-003) |

| R09 | 외상매출금명세서 합계 = 표준 외상매출금 | 차이 |
| R10 | 소득금액조정합계표 익금산입 합계 = 코드02 | 차이 |
| R11 | 공제감면합계표 총계 = 코드17 + 19 | 차이 |
| R12 | 표준재무제표 = 결산서 (대분류) | 서식 간 차이 — 표준 값 유지(Q-012) |
| R14 | 가수금명세서 합계 = 표준 코드236/292, 없으면 **같은 금액의 부채 계정**(4차) | 같은 금액 계정이 없으면 서식 간 차이 |
| R15 | 선납세금 증가 vs 기납부세액 공란 | 확인 필요(원인 판단 안 함) |

| R18 | 대여금 명세서 합계 = 인정이자조정명세서(을) 가지급금 잔액 | 서식 간 차이 |

모든 차이는 **어느 값이 맞는지 판단하지 않고** 표시한다. 보고서 재무 숫자는 표준재무제표 값(Q-012).

## 5. 계산 보류와 경고

- `calc()`: 입력이 모두 확정·계산·가정이면 계산, 하나라도 «확인 필요»면 결과도 «확인 필요»(플래그 `계산보류`)와 보류 사유.
- 경고는 **원인 단위**로 묶는다. 계산 보류는 원인 경고의 ‘보류된 계산’ 목록으로 붙이고, 명세서의 가림 칸은 명세서·페이지 단위로 묶는다.
- 경고 항목: 구분(값 확인 필요/계산 보류/서식 간 차이) · 연도 · 파일 · 서식 · 페이지 · 항목 · PDF 표시값 · 판단(PDF 표시 그대로/추출 문제/자료 부족/서식 간 숫자 차이) · 조치 · 질문.
