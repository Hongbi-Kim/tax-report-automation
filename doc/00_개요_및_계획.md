# 00. 개요 — 법인세 보고서 자동화 (최종)

> 최종 정리: 2026-11-21 · 1~4차 모두 통과

## 1. 무엇을 만들었나

같은 회사의 **전기·당기 세무조정계산서 PDF 2개**를 넣으면 다음을 만드는 프로그램이다.

| 산출물 | 형식 | 비고 |
|---|---|---|
| **법인세 분석 보고서** | PDF (+ HTML) | 제출·채점 대상. 숫자마다 PDF·서식·페이지 근거 |
| 조정료청구서 | PDF (+ HTML) | 기본보수는 담당자 보수표로 계산, 가산율·부가세는 미정이라 «확인 필요» (채점 대상 아님) |
| 경고 목록 | CSV + 경고 위치 캡처 PNG | 파일·연도·서식·페이지·항목·표시값·판단·조치 |
| 근거 대장 | JSON (보고서 부록 E에도 수록) | 보고서에 쓴 모든 값의 원문·계산식·상태 |
| 질문 기록부 | `config/questions.yaml` (보고서 부록 D) | «답변 있음 / 불명확·충돌 / 답변 없음», 처음 질문은 지우지 않음 |

## 3. 지킨 원칙

1. **값마다 근거** — 모든 숫자에 `파일 · 서식 · 페이지 · 항목(코드)`과 PDF 원문 줄을 남긴다. 계산값은 계산식과 입력값을 남긴다.
2. **확정되지 않은 값은 사실처럼 쓰지 않는다** — 회색 가림·글자 표기·합계 빈칸·서식 없음은 «확인 필요», 그 값에 의존하는 계산만 보류한다. 빈칸을 0으로 넣거나 다른 서식에서 임의로 가져오지 않는다.
3. **서식끼리 맞춰 본다** — 같은 항목이 여러 서식에 있으면 대사하고, 다르면 같은 범위의 값인지 먼저 확인한 뒤 근거 없이 덮어쓰지 않고 경고로 남긴다.
4. **이름이 비슷하다고 같은 항목으로 보지 않는다** — 열 머리글·세무서식·거래처·금액 일치로 의미와 집계 범위를 확인한다(예: 당기발생액 ≠ 공제세액, 기타당좌자산 → 인정이자조정명세서로 가지급금 확인).
5. **회사별 정답을 코드에 넣지 않는다** — 모든 읽기 규칙은 서식 형식(머리글·코드 위치·표기 방식) 기준.
6. **실행마다 새 폴더** — 이전 결과를 덮어쓰지 않는다. 고치기 전 첫 결과와 당시 프로그램 사본을 보관한다.

## 4. 처리 흐름

```
PDF 2개 ─▶ ① 페이지·서식 식별 (pdfsrc.py)
             제목 규칙·정규식, 이어지는 쪽 상속, 회색 가림 도형·안내 문구 감지
         ─▶ ② 서식별 추출 (extract.py)
             칸마다 숫자 / 글자 표기 / 가림 / 빈칸 구분, 머리글 기준 좌표, 체크 표시(○) 판독
         ─▶ ③ 회사·연도 확인 (사업자번호 일치·연속 사업연도, 빈 값끼리는 불일치)
         ─▶ ④ 대사·검산 (build.py, R01~R18)
         ─▶ ⑤ 계산·코멘트 — 확정값만으로 계산, 아니면 계산 보류 (build.py)
         ─▶ ⑥ 경고 묶기 — 원인 단위, 보류된 계산을 영향으로 첨부
         ─▶ ⑦ 출력 — 보고서·청구서 PDF, 경고 CSV·캡처, 근거 대장 (render.py, charts.py, fee.py)
```
