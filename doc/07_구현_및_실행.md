# 07. 구현 및 실행 (최종)

## 1. 실행

```bash
cd FF
PYTHONPATH=src python3 -m taxreport \
  --prior   tax/<회사>_<전기>_세무조정계산서.pdf \
  --current tax/<회사>_<당기>_세무조정계산서.pdf \
  --out out/<실행 이름>

# 테스트 (샘플 기대값 8건)
PYTHONPATH=src python3 -m pytest tests -q
```

- 결과는 `out/<실행 이름>/<회사>_<당기>_<실행시각>/`에 **새로 만들어진다**(덮어쓰지 않음).
- 같은 회사의 연속 2개 사업연도가 아니거나 사업자번호를 읽지 못하면 실행을 멈춘다.
- 필요 환경: Python 3.11, `pdfplumber`, `jinja2`, `pyyaml`, `matplotlib`, Google Chrome(헤드리스 PDF 변환), Pretendard 폰트(없으면 Apple SD Gothic Neo).

## 2. 출력 파일

| 파일 | 내용 |
|---|---|
| `<회사>_<당기>_법인세분석보고서.pdf` / `.html` | 제출용 보고서 |

| `<회사>_<당기>_법인세분석보고서_근거대장.json` | 모든 값의 근거·상태·계산식 |

## 3. 코드 구조

| 파일 | 역할 |
|---|---|
| `src/taxreport/pdfsrc.py` | 글자 좌표 읽기, 붙은 토큰 분리(`163,718,790II.비유동자산`), 줄 묶기, 서식 식별(제목 규칙·정규식·이어지는 쪽 상속), 회색 가림 도형·「실습용」 안내 감지 |
| `src/taxreport/extract.py` | 서식별 추출기. 공통 `cell()`이 칸을 숫자/글자 표기/가림/빈칸으로 구분. 신고서(체크 표시 ○ 판독 포함), 세액조정계산서(코드 앵커·붙은 코드·나뉜 코드), 표준재무제표(「코드」 머리글 기준 좌우 단, 두 줄 항목명), 결산서(당기·전기 열), 결손금, 소득금액조정, 기업업무추진비, 공제감면(열 머리글로 의미 결정), 인정이자조정명세서(을), 지방소득세, 결산부속명세서 |
| `src/taxreport/models.py` | `Evidence`(파일·서식·페이지·항목·원문·bbox), `Value`(값·상태·플래그·계산식·질문) |
| `src/taxreport/build.py` | 회사·연도 확인, 대사·검산(R01~R18), 장별 내용, 코멘트, 계산 보류, 경고 묶기 |
| `src/taxreport/charts.py` | 그래프 4종(확정값만 그림, 나머지는 ‘확인 필요’ 표시) |
| `src/taxreport/fee.py` | 조정료 계산(보수표, 기준금액, 보류) |
| `src/taxreport/render.py` | 값 표시 규칙(«확인 필요», –, ※, A), HTML→PDF(헤드리스 Chrome) |
| `src/taxreport/templates/report.html.j2`, `fee.html.j2` | 보고서·청구서 레이아웃 |
| `src/taxreport/__main__.py` | 실행 진입점, 새 출력 폴더, 경고 CSV·캡처, 근거 대장 JSON |
| `tests/test_sample.py` | 샘플컴퍼니 기대값(표준재무제표·세액·충돌 감지·대사·명세서·체크 표시·조정료) |

## 4. 설정 (`config/`)

| 파일 | 내용 |
|---|---|
| `firm.yaml` | 발행 법인명·문구, `sga_top_n: 5`(판관비 주요 항목 개수, Q-4-01) |
| `fee_schedule.yaml` | 조정료 보수표 8구간(Q-002-1), 가산율·부가세 미정, CMS 출금일·피드백 요청일(관리자 설정) |
| `questions.yaml` | 질문 기록부(보고서 부록 D 원본)와 가정 목록(부록 A) |

담당자 답변이 오면 `questions.yaml`에 답변을 추가하고 다시 실행한다. 답이 보고서 규칙을 바꾸는 경우(예: 판관비 개수)는 설정값으로, 그 외 표시 방식 변경은 코드 수정이 필요하다.

## 5. 회귀 확인 방법

규칙을 고칠 때마다 이전 단계 정상 자료를 모두 다시 실행해 근거 대장 JSON끼리 비교했다(같은 근거 위치·키의 값·상태 비교). 4차 최종 기준 1·2·3차 자료 모두 **값 차이 0건**.

| 자료 | 명령의 입력 |
|---|---|
| 1차 | `샘플컴퍼니_2024/2025_세무조정계산서.pdf` |
| 2차 | `샘플컴퍼니2_2024/2025_세무조정계산서_재송부.pdf` |
| 3차 | `샘플컴퍼니4_2023/2024_세무조정계산서.pdf` |
| 4차 | `샘플컴퍼니3_2023/2024_세무조정계산서.pdf` |
