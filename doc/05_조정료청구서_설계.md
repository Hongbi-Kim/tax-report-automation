# 05. 조정료청구서 설계 (기본보수 확정 · 가산보수 미정)

> 2026-11-21 갱신: 과제 안내에 따라 조정료청구서를 다시 범위에 넣음(채점 대상은 아님). 담당자 회신으로 기본보수 구간표 확정(Q-002-1) → `config/fee_schedule.yaml`, `src/taxreport/fee.py`, `templates/fee.html.j2`. 가산 비율·부가세·원 단위·기존 양식은 미정(Q-002-2). 출력: 실행 폴더마다 `<회사>_<당기>_조정료청구서.pdf`. 매출액·자산총계가 «확인 필요»면 기준금액·기본보수도 보류(2차 가림 자료에서 확인)

> (이력) 2026-11-21 한때 “최종 분석 보고서만” 지시로 범위에서 뺐다가, 과제 안내(출력 = 보고서 + 조정료청구서)에 따라 다시 넣음.

> (이력) 보수표를 받기 전에는 금액을 모두 «확인 필요»로 두었다. 현재는 기본보수만 계산, 가산보수·부가세·합계는 «확인 필요».

## 1. 받은 규칙 (요구사항 C24~C30)

1. 기본보수: **매출액**과 **자산총계의 1/2** 중 큰 금액을 기준으로 산정
2. 공제·감면액이 있으면 공제·감면액에 일정 퍼센트를 곱해 가산
3~5. (비어 있음)
6. CMS 출금일·피드백 요청일은 관리자가 설정(전 고객 동일)
7. 참고링크(젠스파크) — 링크 없음

## 2. 계산 구조 (보수표만 끼우면 동작하게)

```
기준금액 = max(당기 매출액, 당기 자산총계 × 1/2)        ← 확정 가능
기본보수 = 보수표(기준금액)                               ← Q-002 대기
가산보수 = Σ (공제감면액_i × 가산율_i)                    ← Q-002 대기
합계     = 기본보수 + 가산보수 (− 할인) (+ 부가세?)         ← Q-002 대기
```

샘플 기준금액: max(192,734,983, 62,210,447 ÷ 2 = 31,105,224) = **192,734,983원 (매출액)**
샘플 공제감면: 중소기업특별세액감면 604,360원

```yaml
# config/fee_schedule.yaml  — 담당자 답변 후 채움
basis: max(revenue, total_assets/2)
brackets:            # 기준금액 구간별 기본보수 (미정)
  - {upto: null, fee: null}
credit_surcharge:    # 공제감면 종류별 가산율 (미정)
  default_rate: null

rounding: null       # 천원/만원 단위 절사 여부 (미정)

# config/firm.yaml
firm_name: 샘플세무법인

```

## 4. 미정 사항

- 구간별 보수표, 공제감면 가산율, 최저·최고 보수, 부가세 처리
- “기존 청구서에 상세내역을 합친다”는 기존 청구서 양식(요구사항 C5 문장이 끊김)
- 기준연도: 당기만 쓰는지(가정 A-004: 당기)
