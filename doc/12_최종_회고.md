# 12. 최종 회고 (2026-11-21)

| 차수 | 무엇이 문제였나 | 무엇을 배웠나 → 프로그램에 남긴 것 |
|---|---|---|
| 1차 | 요구사항 문서와 출력예시의 목차가 달랐고, 판관비 선정 기준 등 정해지지 않은 것이 많았음 | 질문은 «질문/필요한 이유/관련 파일·페이지/답에 따라 달라지는 구현»으로. 답 없는 항목은 가정(A-xxx)으로 진행하되 보고서 부록에 드러냄 |

## 2. 잘 된 것

- **근거 대장 비교로 회귀 확인**: 규칙을 고칠 때마다 이전 단계 자료의 근거 대장을 값 단위로 비교해 “기존 입력에 미친 영향”을 숫자로 보여 줄 수 있었다(4차 최종 기준 1~3차 값 차이 0).
- **덮어쓰지 않는 실행 폴더**: 차수마다 ‘수정 전 첫 결과 + 당시 프로그램 사본’을 남겨 전후 비교가 가능했다.
- **경고 캡처**: 경고 위치를 PDF에서 잘라 저장해, ‘PDF에 실제로 보이는 내용인지 추출 문제인지’를 사람이 바로 대조할 수 있었다.

## 3. 아쉬운 것 / 실수

- 1차 회귀 확인 중 1차 결과 파일을 한 번 덮어씀 → 보관해 둔 1차 프로그램으로 재생성. 이후 실행마다 새 폴더로 바꿈.
- 담당자 답변 “상위 고정 5개”를 처음에 «답변 있음»으로 분류했으나 ‘고정’의 뜻이 모호했음 → 후속 질문(Q-4-02)으로 다시 물음. 모호한 단어가 있으면 분류 전에 해석을 적어 두기.
- 보고서 PDF의 숫자가 텍스트로 추출되지 않는 문제를 3차 때 출력에서 보고도 넘어감 → 출력 확인은 ‘화면’과 ‘텍스트 추출’ 둘 다 하기.
- 채점 항목 목록을 일찍 확인하지 못해, 4차에서 채점과 무관한 ‘6번째 항목’ 기준을 먼저 의심함.
